# Trädgårdskarta

Ett webbverktyg för att ladda upp en enkel karta över trädgården, markera områden och skriva vilka växter som finns där.

Öppna verktyget: https://sweblix.github.io/tradgardskarta/

## Så här gör du

1. Ladda upp en kartbild (.jpg eller .png).
2. Välj färg och tjocklek.
3. Håll in vänster musknapp och rita på kartan.
4. Välj "Sudda" för att sudda ut färg.
5. Välj "Text" och klicka på ett färgat område för att skriva vilken växt som finns där. Varje område kan ha en text. Klicka på texten för att ändra eller ta bort den, eller dra i den för att flytta den.
6. Klicka på "Spara bilden som PNG" längst ned för att spara kartan som en bild.

Bilder som du laddar upp stannar i din egen webbläsare och skickas inte någonstans.
