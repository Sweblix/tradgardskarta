# Trädgårdskarta

Ett webbverktyg för att ladda upp en enkel karta över trädgården, markera områden och skriva vilka växter som finns där.

Öppna verktyget: https://sweblix.github.io/tradgardskarta/

## Så här gör du

1. Ladda upp en kartbild (.jpg eller .png).
2. Välj färg och tjocklek.
3. Håll in vänster musknapp och rita på kartan.
4. Välj "Sudda" för att sudda ut färg.
5. Välj "Text" och klicka på ett färgat område för att skriva vilken växt som finns där. Varje område kan ha en text. Klicka på texten för att ändra eller ta bort den, eller dra i den för att flytta den.
6. Klicka på "Spara bilden som PNG" längst ned för att spara kartan som en bild.
7. Ångra med knappen "Ångra" eller Ctrl+Z.
8. Zooma med mushjulet eller knapparna −, + och "Hela kartan". Flytta kartan när du har zoomat in genom att hålla in mellanslag och dra, eller dra med mushjulet intryckt.

## Rita en egen karta

- Klicka på "Rita egen karta" (eller "Ny tom karta") för att få ett vitt papper med rutnät.
- Välj "Linje" och klicka där linjen ska börja och vid varje hörn. Dubbelklicka eller tryck Enter för att avsluta.
- Håll in Shift för exakt vågrätt, lodrätt eller 45°. Klicka på startpunkten för att stänga en figur, t.ex. ett hus.
- Klicka på en befintlig linje för att ta bort den. Linjeverktyget fungerar även på uppladdade kartor.
- Rutnätet följer inte med när du sparar som PNG.

## Spara och fortsätta senare

- Kartan sparas automatiskt i webbläsaren och öppnas igen nästa gång du besöker sidan (i samma webbläsare på samma dator).
- Klicka på "Spara projekt" för att spara kartan som en fil. Den kan du öppna igen med "Öppna projekt", även på en annan dator, och fortsätta ändra.

Bilder som du laddar upp stannar i din egen webbläsare och skickas inte någonstans.
